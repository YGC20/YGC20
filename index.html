BoatControl WIP

GitHub ↗

YOLOv8n 객체 탐지 + 리눅스 커널 드라이버(ioctl/IRQ 기반) 제어로 구현하는 자율 쓰레기 수거 보트 제어 시스템. 학습 목적으로 진행 중인 미완성 프로젝트입니다.

Contribution

  • 아키텍처 3단계 전환: 라즈베리파이 단일 보드(Python) → C++ 전환 → 노트북(영상 처리)·Zynq 보드(모터 제어) 2-장비 구조로 직접 재설계
  • vision ↔ boat 통신 프로토콜 설계: 패딩 없는 고정 크기 UDP 패킷(DetectionPacket) 구조체로 한 데이터그램 = 한 프레임 탐지 결과가 되도록 구현
  • 리눅스 커널 드라이버 직접 구현: 모터는 ioctl 기반 캐릭터 디바이스로, 초음파 센서는 IRQ 기반 펄스 폭 측정으로 각각 커널 모듈 작성
  • stub/dev 이원화 설계: 실장치 없이도 로직을 검증할 수 있도록 CMake 옵션으로 stub ↔ 실장치 구현을 전환 가능하게 구성

Review

  • HW/SW 인터페이스 이해: 논리적 코드가 실제 하드웨어의 물리적 동작으로 변환되는 제어 루프를 직접 구현하며 신호 처리와 타이밍 동기화의 중요성을 체득했습니다.
  • 미완성을 인정하는 것도 실력: 실기기 종합 테스트와 커스텀 학습 모델 등 남은 작업량 대비 시간이 부족해 현재 상태로 일단락하고 진행 상황을 있는 그대로 문서화했습니다.

LookAtCat Vision

2026.08 – 2026.09

GitHub ↗

OpenCV + dlib 기반 얼굴 추적으로 웹캠 앞 사람의 시선을 따라 움직이는 WPF 캐릭터 인터랙션.

Contribution

  • 멀티스레드 파이프라인 설계: 캡처·검출·렌더링을 별도 스레드로 분리하고, 처리 지연이 누적되지 않도록 큐 대신 "최신 값 하나만 lock으로 덮어쓰는" 방식으로 데이터 전달
  • 상태 기반(FSM) 캐릭터 동작 구현: Tracking → HoldLast → RandomWalk 3단 상태머신으로, 얼굴을 놓쳐도 자연스럽게 이어지는 시선 움직임 설계
  • 설계 전환 경험: 동공 위치 기반 시선 추적보다 얼굴 위치 기반 추적이 더 안정적이라고 판단해 최종 로직을 교체 (동공 검출은 디버그 용도로 유지)

Review

  • 가설이 틀렸을 때의 대응: 처음 설계(동공 기반)가 최선이 아니라는 걸 직접 실행해보며 확인했고, 코드와 커밋 이력에 그 전환 과정을 그대로 남겨 판단 근거를 기록했습니다.
